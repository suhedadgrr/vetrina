# Vetrina

Vetrina ajans web sitesi (statik, GitHub Pages).

- `index.html`: ana sayfa
- `docs/social-content-plan.md`: ilk 30 gün sosyal medya planı

## Yayın
GitHub Pages, `.github/workflows/pages.yml` ile `main` dalından yayınlanır (Settings → Pages → Source: GitHub Actions).

## Yapılacaklar
Yer tutucuları (`[X]`, `[telefon]`, `[FORM_ID]`, `[e-posta]`) doldurun, sonra `index.html` içindeki `noindex` satırını silin.
